# Mohsen Izi — CV

This is my personal CV website. I'm a mobile developer building cross-platform apps (Android, iOS, Web) with **Flutter** and **Dart**, including the AI apps Findora, Dana and Doktorify.

**Live site:** https://moh3niziy.github.io/CV/

## What's on the site

- **Profile:** photo, contact details and social links
- **Resume:** summary, work experience, projects, skills, education and languages
- **English and Persian:** switch with the button at the top (Persian is shown right-to-left)
- **PDF export:** the "Save as PDF" button prints a clean copy of the resume

## Built with

Plain HTML, CSS and JavaScript in a single file (`index.html`). There's no framework and no build step. Just open the file in a browser.
