# سامانهٔ نوبت‌دهی آرایشگاه

وب‌سایت فارسی و کاملاً استاتیک (بدون سرور) برای مدیریت نوبت‌های آرایشگاه، قابل انتشار رایگان روی GitHub Pages.

- **نمای مشتری** (صفحهٔ اصلی): انتخاب آرایشگر و روز، مشاهدهٔ زمان‌های خالی و تماس برای رزرو.
- **پنل مدیریت** (دکمهٔ «ادمین»، رمز `1234`): تعریف آرایشگرها با شماره تماس، ساعت کاری هفتگی و خدمات (نام + مدت زمان)، و ثبت نوبت با انتخاب یک‌کلیکی خدمات. زمان پایان خودکار محاسبه و از تداخل نوبت‌ها جلوگیری می‌شود.

## ذخیرهٔ داده‌ها

همهٔ اطلاعات در فایل [`data.json`](data.json) پروژه است و سایت هیچ سرور یا سرویس خارجی ندارد:

- سایت هنگام باز شدن `data.json` را می‌خواند.
- تغییرات پنل ادمین فوراً در حافظهٔ مرورگر همان دستگاه ذخیره می‌شود.
- در پنل ادمین (تب «آرایشگرها» → «فایل داده‌ها») با **دانلود data.json** فایل به‌روز را بگیرید و جایگزین فایل پروژه کنید؛ با **بارگذاری فایل** هم می‌توانید یک فایل داده را برگردانید.
- اگر `data.json` پروژه از دادهٔ ذخیره‌شده در مرورگر جدیدتر باشد، سایت نسخهٔ جدیدتر را نمایش می‌دهد.

## انتشار روی GitHub Pages

1. پروژه را در یک مخزن گیت‌هاب push کنید.
2. در مخزن: **Settings → Pages → Build and deployment**، گزینهٔ **Deploy from a branch**، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید.
3. سایت روی `https://USERNAME.github.io/REPO/` در دسترس است.

## اجرای محلی برای تست

مرورگرها اجازهٔ خواندن `data.json` از `file://` را نمی‌دهند؛ برای تست محلی:

```bash
python3 -m http.server 8000
```

## ساختار

- `index.html`، `styles.css`، `app.js` — رابط کاربری (تم روشن و تیره، واکنش‌گرا، تقویم شمسی)
- `data.json` — داده‌های آرایشگاه
