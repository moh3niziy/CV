# Project images

One folder per project, named after the project:

```
<project>/
├── icon.png          # app icon, square, at least 256×256 (PNG or WebP)
└── screenshots/      # app screenshots, numbered in display order
    ├── 1.png
    ├── 2.png
    └── ...
```

Keep each image under ~300 KB (WebP is smallest) so the site stays fast.
